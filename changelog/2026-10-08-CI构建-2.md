### GitHub Actions：构建 debug 与 release 两个 APK 产物

- 新增 `.github/workflows/build.yml`，推 `master` / `main` / `v*` 标签、开 PR、手动触发时各跑一次。
- 构建环境：JDK 17 + Android SDK（platform 36 / build-tools 36.0.0），开 Gradle 缓存。
- 签名：配了 `KEYSTORE_BASE64` / `KEYSTORE_PASSWORD` / `KEY_ALIAS` / `KEY_PASSWORD` 四个 secrets 就写 `keystore.properties` 走正式签名；没配则退回 debug 签名并打一条 notice。
- 产物：文件名带 `WubiModule.BUILD_ID`，debug 与 release 各上传一个 artifact。
